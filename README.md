# مدير المصاريف — نسخة Supabase + GitHub Pages

تم نقل التطبيق بالكامل من Google Apps Script إلى:
- **قاعدة البيانات:** Supabase (PostgreSQL)
- **الاستضافة:** GitHub Pages
- **تسجيل الدخول:** Supabase Auth (بريد إلكتروني + كلمة مرور)
- **PWA:** يقبل التثبيت على الموبايل والكمبيوتر

## لماذا فيه تسجيل دخول دلوقتي؟

الداتا اللي كانت في Google Apps Script كانت محمية تلقائيًا لأن الرابط ده كان محتاج حسابك في جوجل. لما التطبيق بيتنقل لـ GitHub Pages (استضافة عامة) والداتا بيز بتتكلم من المتصفح مباشرة، أي حد يعرف الرابط ومفتاح الـ anon key هيقدر يشوف ويعدّل بياناتك المالية لو مفيش تسجيل دخول. عشان كده ضفت طبقة حماية (Auth + Row Level Security) بحيث كل جدول مربوط بـ `user_id` وميظهرش غير لصاحب الحساب.

## 1. إعداد Supabase

1. اعمل مشروع جديد على [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل محتوى ملف `supabase-schema.sql` المرفق — هيعمل الجداول الأربعة (`transactions`, `cc_plans`, `fixed_expenses`, `budgets`) ويفعّل الـ RLS.
3. من **Authentication → Users** أضف مستخدم واحد بالبريد وكلمة المرور اللي هتستخدمها للدخول (مفيش داعي لتسجيل عام، التطبيق شخصي).
4. من **Project Settings → API** انسخ:
   - `Project URL`
   - `anon public key`

## 2. ربط التطبيق بالمشروع

افتح `index.html` وحدّث السطرين دول في أول الـ `<script>` الأخير:

```js
const SUPABASE_URL = "https://YOUR-PROJECT-REF.supabase.co";
const SUPABASE_ANON_KEY = "YOUR-ANON-KEY";
```

الـ anon key آمن إنه يكون ظاهر في كود الفرونت إند — هو مصمم لكده — الحماية الفعلية جايه من الـ RLS policies.

## 3. رفع المشروع على GitHub Pages

1. اعمل ريبو جديد على GitHub وارفع الملفات: `index.html`, `manifest.json`, `sw.js`, `icons/`.
2. من إعدادات الريبو: **Settings → Pages → Source** اختار الـ branch (عادةً `main`) والمجلد `/ (root)`.
3. بعد شوية هيديك رابط زي: `https://username.github.io/repo-name/`.

> لو عايز الريبو يفضل خاص، GitHub Pages من ريبو خاص محتاج خطة GitHub Pro/Team — لو الريبو عام أي حد هيقدر يشوف الكود (مش الداتا، الداتا محمية بالـ RLS).

## 4. تثبيت التطبيق (PWA)

- **على الموبايل (Android/Chrome):** افتح الرابط، هيظهر اقتراح "إضافة إلى الشاشة الرئيسية" أو من قائمة المتصفح ⋮ اختار "Install app".
- **على iPhone (Safari):** من زر المشاركة اختار "Add to Home Screen".
- **على الكمبيوتر (Chrome/Edge):** هيظهر أيقونة تثبيت ⊕ في شريط العنوان، أو من القائمة اختار "Install مدير المصاريف".

بعد التثبيت التطبيق هيفتح في نافذة مستقلة زي أي تطبيق عادي، وهيشتغل أوفلاين جزئيًا (الواجهة بس، البيانات محتاجة إنترنت).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة كاملة + منطق الاتصال بـ Supabase |
| `manifest.json` | إعدادات التثبيت (PWA) |
| `sw.js` | Service Worker لتخزين الواجهة والعمل أوفلاين |
| `icons/` | أيقونات التطبيق |
| `supabase-schema.sql` | أوامر إنشاء الجداول والحماية |

## ملاحظات تقنية

- الحقول اتغيرت من `rowIndex` (رقم صف في الشيت) إلى `id` (مفتاح أساسي في Postgres) — منطق التعديل والحذف بقى بالـ `id`.
- كل الحسابات (الأرصدة، تقرير الأقساط، الرسم البياني) اتنقلت تتحسب في الفرونت إند بنفس منطق GAS الأصلي بالظبط.
- لو حبيت تضيف تصنيفات أو أعمدة جديدة، عدّل في `supabase-schema.sql` وفي الـ `<select>` بتاعة التصنيفات في `index.html`.
